- [ ] Homepage

- [ ] Orders: history, detail, live status, cancel (Pending/Accepted) with stock restore
- [ ] Admin: dashboard stats, manage orders, food, stock, students, notifications (realtime), locations, reports
- [ ] Payment: Pay Now, Razorpay test mode only when keys are set, backend verification
- [ ] Location tracking: manual + device GPS, stops after delivery/cancel
